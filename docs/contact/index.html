    Before you send

    Five things that decide your quote price

    1. File format

    STEP or IGES. Native CAD files cause version-mismatch import errors, and STL alone needs remodelling before it can be quoted.

    2. Marked tolerances

    Flag the functional dimensions and let the rest ride at ISO 2768-m. This one habit typically saves 15–25% on precision parts.

    3. Thread callouts

    Size, pitch, depth and class on the drawing. “Add threads where needed” is the single most common cause of quote delay.

    4. Real quantities

    “5 now, 50 in Q3” lets us design the fixture for the transition. Fixtures designed on prototype day make production day cheap.

    5. Material and finish

    Alloy, temper, anodise type and colour, surface roughness target. One sentence prevents one re-make.
